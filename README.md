# 🚀 Projeto Zoom

Este projeto é uma recriação da página inicial do Zoom, desenvolvida com HTML5 e CSS3 como forma de praticar conceitos de desenvolvimento front-end.

## ✨ Funcionalidades

- Layout moderno inspirado no site do Zoom
- Design responsivo
- Utilização de CSS Grid
- Utilização de Flexbox
- Botões com efeito hover
- Organização do código em HTML e CSS

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

---

## 📚 O que pratiquei

Durante este projeto foram praticados conceitos como:

- Estrutura semântica em HTML
- Posicionamento com Flexbox
- Criação de layouts com CSS Grid
- Responsividade utilizando Media Queries
- Organização de estilos em arquivos separados

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/projeto_zoom.git
```

2. Abra o arquivo `index.html` no navegador.
